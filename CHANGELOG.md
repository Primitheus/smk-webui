# Changelog

## 0.2.0-rc.1

- Simple controls and an eight-layer lighting studio with audio and screen colour sources.
- Eighteen built-in presets, animated previews and personal preset editing.
- Layer reordering, key masks, undo/redo and Solo preview.
- Persistent drafts and preset library import/export with recovery backups.
- Onboard colour modes, key assignments, macros and scoped resets for supported X77 firmware.
- Dark, light and system themes, tray controls and optional Windows startup.
- Clear stale firmware details after a lighting transport failure.
- Preserve startup preferences on upgrades and wait for shutdown before replacing files.

This is a release candidate. Physical sleep/wake, audio/display device replacement and installed upgrade/uninstall still need a complete acceptance test. No firmware update is required for this app release.
